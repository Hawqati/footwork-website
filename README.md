# FOOTWORK website

Complete Next.js website for FOOTWORK – Dutch Football Performance Academy.

## GitHub / Vercel
1. Upload the CONTENTS of this folder to the root of your GitHub repository.
2. In the GitHub root you must immediately see: `app`, `public`, `package.json`, `next.config.mjs`.
3. Import the repository in Vercel. Framework Preset: Next.js. Root Directory: `./`.
4. Deploy.

All site images and the FOOTWORK logo are included under `public/images/`.

## Local test
```bash
npm install
npm run dev
```

The current form uses `mailto:info@footworkacademy.nl` as a placeholder. Replace this email or connect a form backend before production use.
